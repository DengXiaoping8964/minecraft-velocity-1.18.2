# NoCap 1.18.2 Speed

Minecraft **1.18.2 Fabric** 的速度上限模组，面向自己开服的场景。

## 它改了什么

- **矿车**：`getMaxSpeed` 提到 5 格/刻（100 格/秒），并去掉铁轨上的原版速度钳制。
- **鞘翅 + 烟花**：烟花推进按刻累积加速，3 刻内连续推进时速度从 1.7 逐步升到 17 格/刻（340 格/秒），并移除滑翔时的水平阻力。
- **服务端移动校验**：加速刚发生的 3 刻内，跳过 `onPlayerMove` 里对鞘翅「移动过快」的检查；矿车有乘客时允许服务端驱动的车辆移动。
- **HUD**：左上角显示当前速度（格/秒，取根载具）。

改动同时包含客户端与服务端 mixin（`environment: "*"`）。单人/局域网由内置服务端生效；多人服务器需要装在服务端，客户端只影响 HUD。

## 注意

它有意突破原版速度上限，并放宽了对应的服务端校验，**只应装在自己控制、且允许这类改动的服务器上**。用在别人的服务器上等同于作弊，后果自负。

## 构建

- JDK 17、Gradle 8.7、Fabric Loom 1.6.12
- `gradle build`，产物在 `build/libs/`
- 运行时：Fabric Loader ≥ 0.14.11、Minecraft 1.18.2、Java 17（不需要 Fabric API）
